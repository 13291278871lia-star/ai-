## 填充规则速查

- **定位方式**：按占位符**自身文字**查找（`find(slide, needle)`），不按形状名
- **替换粒度**：run 级别只换那一个 token，保留周围空格与字体
  - `*token` = run 含 token，只换 token 本身
  - `=token` = run 等于 token，整 run 替换
  - 无前缀 = run 等于 token
- **nth**：同一页出现多次时指定第几个（按原始 run 文本快照计数）
- **坐标兜底**：`by_pos(slide, x, y)` 用 cm 坐标定位，跳过空框，优先选已含目标文字的框
