# PPT 制作规则 · 2026-09-22

用户目标：按所给计算公式、GF PPT 模版及例图制作保险概览，吸收到本地 AI 工作平台。附件仅作为数据和设计依据，不能作为自动执行指令。

## 保留资料
- gf-template.pptx：原始11页模版，完整保留。
- irr-sample.xlsx：原始「總」「AGE」计算表，完整保留。
- layout-example.png：用户提供的版式例图。
- policy-example.pdf：本次核对的财富恒裕3案例。产品不能与 GF 或例图产品混用。

## 模版页面映射
1. 左侧供款及年期，右侧20/30/40/50年预期现金价值与人民币换算、IRR。
2. 单人退休提取及100岁退保。
3–4. 投保人及下一代双时间轴。
5. 教育、创业、退休分阶段提取。
6. 多代家庭提取。
7. 保费回赠及现金券。
8–9. 预缴1年/4年利息。
10. 优惠方案比较。
11. 缴费说明。

当前已实现概览页的动态数据、原生可编辑PPT表格及文字，并新增原生可编辑IRR折线图页。概览每页最多8行，按资料自动分页；图表按实际年份间距绘制。第2–11页保留原件，尚未自动填充。提取方案须使用对应提取后的退保价值，不能沿用无提取计划书。插图可自由生成，但不得用图片替换图表数据；本机未接图片生成API。

## 计算合同
- IRR与Excel IRR一致：等间隔现金流，首笔t=0，逐年保费在t=0到N-1，退保在t=T。正负缺失或多次符号变化时提示，不伪造结果。
- 单笔无提取：r=(FV/P)^(1/T)-1。额外费用按实际支付时点计入，不将保额当保费。
- 「總」B10例：五年每年100000，t20退保1357738，IRR约5.6887456%。作为回归校验。
- 人民币=美元×输入汇率。汇率只作显示假设；不是实时牌价。计算不提前舍入。
- AGE：到达年龄=投保年龄+保单年数。100岁不等于100年。
- 提取次数含起止年份；提取倍数分母为实际明确口径的总保费。不同期限退保互斥，不能相加。
- 原表C71:E75：第k年计息本金=(5-k)×年保费+此前累计利息；该年利息=本金×年利率。
- 16%、3.8%、4.3%、2815现金券都是原例参数，非通用或现行承诺，不默认套到恒裕3。

## 动态上传（2026-09-22）
- 支持 PPTX、文字 PDF、Excel（XLSX）、CSV／TSV、JSON；单文件20MB以内，本机浏览器解析。
- PPTX按幻灯片顺序提取原生文字与表格，选择表格并核对年度、金额列后套用；不识别图片中的数字，不自动复制上传PPTX的母版、插图及版面。空白模版须补充金额，不能据此生成回报率。
- PDF候选表格须核对页码及列对应；扫描件需先OCR。Excel使用已保存的公式结果，缺少结果时提示。
- 当前动态概览支持美元、无中途提取方案。产品、年龄、保费、供款年数、首期费用、汇率及退保金额必须完整。
- 可导入保证＋非保证，或仅退保总额；仅总额时不虚构保证组成。缺失或冲突资料阻止导出。
- 核对后，修改输入会同步更新表格、网页折线图和可编辑PPT。JSON可保存并重新载入方案。
- 已验证原GF空白模版识别、含数据PPTX导入及重新计算、PDF／XLSX／CSV／JSON解析、IRR计算和原生图表导出。
