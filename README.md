# AIA AI 工作台

这是可携带、可继续修改的本地网页项目。源代码在 `src/`，资料文件在 `assets/`，本地接口在 `serve.py`。

## 两种链接的区别

- `http://127.0.0.1:4175/` 是本机运行链接，只能在启动服务的这台电脑访问。
- GitHub、GitLab、Gitee 等私人仓库链接是源码协作链接，可以交给其他 AI 工具继续修改。

如要让其他 AI 接手，请提供私人仓库链接，或上传 `AI工作台-源码交接包.zip`。完整资料文件约 1.3GB，不应直接放入公开仓库。

## 在 Mac 启动

1. 解压整个资料夹，不能只打开 `index.html`。
2. 双击 `啟動-AI工作台.command`。
3. 浏览器会打开 `http://127.0.0.1:4175/`。

首次运行如被 macOS 阻止，可在文件上按右键选择“打开”。电脑需要 Python 3。

## 在 Windows 启动

1. 安装 Python 3，并在安装时勾选加入 PATH。
2. 双击 `启动-AI工作台-Windows.bat`。

## 修改位置

- `src/main.js`：导航、页面和产品资料栏目。
- `src/style.css`：颜色、排版和响应式布局。
- `src/insurance-*.js`：PPT、IRR 图表及文件导入。
- `src/medical-compare.js` / `src/medical-compare.css` / `src/medical-compare-data.js`：医疗产品对比中心（六个视图：产品速览 / 内部产品定位 / 市场特性比较 / 保费比较 / 国籍及居住地资格 / 智能推荐）。
- `assets/`：产品、推广、培训、停售产品及参考文件。
- `serve.py`：本地服务和产品资料读取接口。

保存后刷新网页即可看到大多数修改。请保留完整目录结构；直接双击 `index.html` 会因为浏览器安全限制而无法正常读取资料和生成 PPT。

## 安全边界

这是本地工作原型，没有登录及多人权限控制。正式对外部署前，须由公司 IT、资讯安全及合规人员审核；不要把含内部资料的完整包放进公开 GitHub 仓库。

## 医疗产品对比中心

`产品对比` 页面顶部新增两个模式：「医疗产品对比中心」（默认）与「资料库产品对比」（原功能）。用户的模式选择会保存在 `localStorage`，下次访问自动恢复。

医疗对比中心基于 AIA 自愿医保睿选计划与「睿选明珠」医疗计划资料册，整理为六个互相补充的视图：

| # | 视图 | 数据来源 |
|---|---|---|
| 01 | 产品速览与特色 | P.5–8、P.9–10 |
| 02 | 内部产品定位 | P.5–8 |
| 03 | 市场特性比较 | P.54–66 |
| 04 | 保费比较 | P.67–71 |
| 05 | 国籍及居住地资格 | P.86–95 |
| 06 | 智能推荐（客户画像） | 上述全部 + P.5–8 |

新增或修改产品只需编辑 `src/medical-compare-data.js`，UI 与逻辑均无需改动；CSS 全部作用域化于 `.mc-root`，不会影响平台其他模块。
